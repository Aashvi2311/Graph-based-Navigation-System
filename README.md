## Graph-Based Navigation System (C++)

This project implements a graph-based navigation system using:
- Adjacency list representation
- Breadth First Search (BFS)
- Depth First Search (DFS)

Cities are modeled as nodes and routes as edges.

## Implementation steps
- Generated an adjacency list representation to model a graph of locations and routes
- Implemented Breadth-First Search (BFS) and Depth-First Search (DFS) traversals to explore the graph
- Analyzed and understood the differences between BFS and DFS in terms of traversal behavior
- Implemented Dijkstra’s algorithm to compute the shortest path between two locations
- Created a file-based dataset containing distances between cities to simulate real-world navigation data
- Applied Dijkstra’s algorithm on the file-based graph to determine optimal routes
